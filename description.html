Vehicle Parking Management System (ParkEase)

Welcome to the Vehicle Parking Management System! This comprehensive guide will explain the entire project to you step-by-step, file-by-file, and show you exactly how to run it.

1. Project Overview

This project is a Java-based web application built using Servlets, JSP (JavaServer Pages), and Maven. Instead of using a traditional database like MySQL, this project uses File-based storage (.txt files) to store all its data (Users, Vehicles, Transactions, etc.).

It follows a standard MVC (Model-View-Controller) architecture:

  • Model: Represents the data objects (User, Vehicle).
  • View: The user interface built with HTML/CSS and JSP.
  • Controller: Servlets that handle requests from the View, process them via Services, and return responses.

2. Directory Structure

Here is a high-level overview of the project structure:

vehicleparkingmanagementsystem/
├── pom.xml                   # Maven configuration file
├── src/                      # Java Source Code
│   └── com/parking/
│       ├── controller/       # Servlets handling HTTP requests
│       ├── model/            # Data entities (POJOs)
│       ├── service/          # Business logic layer
│       └── util/             # Utility classes (like FileHandler)
└── web/                      # Web Resources (Frontend)
    ├── css/
    │   └── style.css         # Styling for the application
    ├── WEB-INF/
    │   └── web.xml           # Web application deployment descriptor
    └── index.jsp             # The landing page of the website
Note: The JSP pages that are supposed to go inside web/pages/ are currently missing in the directory, but the backend is fully programmed to route to them!

3. File-by-File Explanation

3.1. The Root Files

  • pom.xml
    This is the Maven configuration file. It tells Maven how to build the project and downloads required dependencies automatically. In this project, it downloads: Java Servlet API 4.0.1, JSP API 2.3.3, and JSTL 1.2. It also configures the project to use Java 11 and package the code into a .war file for deployment.

3.2. Web Resources (web/ directory)

  • web/index.jsp
    The main landing page ("ParkEase") you see when you start the application. It contains the "Hero" section, marketing text, and buttons to Login or Register as an Admin/User.
  • web/css/style.css
    Contains all the CSS rules that make the application look modern (dark theme, glassmorphic effects, modern fonts).
  • web/WEB-INF/web.xml
    A configuration file for the web server (Tomcat). It defines the index.jsp as the default welcome page, sets session timeouts (30 minutes), and configures the dataDir (Data Directory) where text files will be saved.

3.3. Models (src/com/parking/model/)

These are plain Java objects (POJOs) used to hold data temporarily in memory before saving to or after reading from text files.

  • User.java
    Holds customer details (ID, name, email, password, phone, address).
  • Admin.java
    Holds administrator credentials.
  • Vehicle.java
    Holds details about registered vehicles (License plate, owner ID, vehicle type).
  • ParkingSlot.java
    Represents a physical parking slot (Slot ID, Floor, Status - Occupied/Available).
  • Transaction.java
    Represents a parking session (Entry time, Exit time, Slot used, User ID).
  • Payment.java
    Records billing information (Transaction ID, Amount, Payment method, Status).

3.4. Controllers (src/com/parking/controller/)

These Servlets intercept URLs requested by the browser (e.g., /user/login).

  • UserServlet.java (/user/*)
    Handles User registration, login, logout, and profile updates.
  • AdminServlet.java (/admin/*)
    Handles Admin authentication and dashboard routes.
  • VehicleServlet.java (/vehicle/*)
    Handles adding a new vehicle, viewing a user's vehicles, etc.
  • SlotServlet.java (/slot/*)
    Handles requests related to checking slot availability and assigning slots.
  • TransactionServlet.java (/transaction/*)
    Handles vehicle check-in and check-out requests.
  • PaymentServlet.java (/payment/*)
    Handles processing payments when a vehicle exits.

3.5. Services (src/com/parking/service/)

Controllers don't do the heavy lifting; they pass data to Services. Services contain the actual "business logic."

  • UserService.java
    Validates if an email is already registered, verifies login credentials against saved text files.
  • AdminService.java
    Handles admin-specific logic.
  • VehicleService.java
    Logic for validating and saving new vehicles.
  • SlotService.java
    Logic to find the nearest available parking slot.
  • TransactionService.java
    Calculates durations and initiates parking sessions.
  • PaymentService.java
    Calculates the final parking fee based on the duration of the transaction.

3.6. Utilities (src/com/parking/util/)

  • FileHandler.java
    The most crucial utility in the project! Since there is no database, this class handles creating, reading, writing, and appending to .txt files inside a data/ folder (which gets created automatically inside the deployed webapp folder).

4. How to Run the Project

Since this is a standard Maven Web Application, you need Java 11+, Maven, and Apache Tomcat (v9) to run it.

Step 1: Install Prerequisites

  1. Java JDK 11 (or higher). Ensure JAVA_HOME is set.
  2. Apache Maven. Ensure mvn is accessible from your command prompt/terminal.
  3. Apache Tomcat 9. Download the ZIP, extract it somewhere on your computer.

Step 2: Build the Project using Maven

Open your terminal/command prompt, navigate to the project root directory, and run:

mvn clean install

What this does: Maven will compile all the Java code in the src/ folder and package it along with the web/ folder into a single file named VehicleParkingSystem-1.0-SNAPSHOT.war located inside a newly created target/ directory.

Step 3: Deploy to Tomcat

  1. Go into the target/ directory of your project.
  2. Find the generated .war file (VehicleParkingSystem-1.0-SNAPSHOT.war).
  3. Copy this file and paste it inside the webapps/ folder of your Apache Tomcat installation directory.
  4. (Optional) Rename the .war file to parking.war to make the URL shorter.

Step 4: Start the Server

  1. Navigate to the bin/ folder inside your Tomcat installation directory.
  2. Run the startup script:
    • Windows: Double-click startup.bat (or run it from cmd).
    • Mac/Linux: Run ./startup.sh in the terminal.

Step 5: Access the Application

Open your web browser and go to:

http://localhost:8080/VehicleParkingSystem-1.0-SNAPSHOT/

(If you renamed the file to parking.war, go to http://localhost:8080/parking/)

You will see the ParkEase hero section!

Note on Data Storage: When you register a user or add a vehicle, the FileHandler.java will create a folder named data/ directly inside the deployed Tomcat folder (Tomcat/webapps/VehicleParkingSystem-1.0-SNAPSHOT/data/) and save text files there.
